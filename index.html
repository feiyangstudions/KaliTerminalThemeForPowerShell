远程安装（推荐）

在 Windows PowerShell 5.1 或 PowerShell 7+ 中执行：

PS> irm ... | iex

本地安装

下载脚本后，在脚本所在目录右键选择“在终端中打开”，执行：

PS> powershell -ExecutionPolicy Bypass -File .\install.ps1
⬇ 下载 install.ps1

说明：install.ps1 采用 UTF-8 with BOM 编码，在 Windows PowerShell 5.1 下可直接运行并正确显示中文。

注意事项

  • 脚本会修改当前用户、当前宿主 PowerShell 的配置文件 $PROFILE。
  • 安装前会自动备份原配置为 .bak；若备份已存在，会询问是否覆盖。
  • 若远程执行被安全策略拦截，可先执行 Set-ExecutionPolicy -Scope Process Bypass 再重试。
  • 安装完成后重新打开终端即可看到 Kali 风格提示符，并可使用 su 打开管理员窗口。
